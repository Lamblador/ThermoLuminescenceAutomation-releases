# ThermoLuminescence Automation — релизы

Публичные **готовые сборки** программы ThermoLuminescence Automation для Windows.

Исходный код приложения в этом репозитории **не хранится**. Здесь только установщики (архивы) и контрольные суммы для проверки целостности.

Релизы: [Releases](https://github.com/Lamblador/ThermoLuminescenceAutomation-releases/releases)

---

## Что это за программа

Приложение для автоматизации экспериментов по термолюминесценции / люминесцентной термометрии: управление нагревом, реле, спектрометром, запись спектров и результатов.

Сборка рассчитана на **Windows 10/11, 64-bit**. Установка Python на лабораторных компьютерах **не нужна**.

---

## Первая установка на компьютер

1. Откройте страницу [последнего релиза](https://github.com/Lamblador/ThermoLuminescenceAutomation-releases/releases/latest).
2. Скачайте файл вида  
   `ThermoLuminescence-<версия>-win64.zip`  
   (например `ThermoLuminescence-1.0.0-win64.zip`).
3. По желанию скачайте соседний файл `.sha256` и проверьте сумму архива (см. ниже).
4. Распакуйте zip в удобную папку, например:  
   `C:\Programs\ThermoLuminescence\`  
   В корне архива должен лежать `main.exe` (не вложенная папка `main`).
5. Запустите `main.exe`.

Рядом с `main.exe` после работы появятся, среди прочего:

- `app_settings.json` — настройки программы;
- `app.log` — журнал;
- `assets\` — переводы и иконка (уже входят в сборку).

Данные экспериментов сохраняются в каталог, указанный в настройках (или в текущую папку, если путь не задан). **Не удаляйте** эти папки при обновлении.

### Проверка SHA-256 (необязательно)

В PowerShell из папки со скачанным zip:

```powershell
Get-FileHash -Algorithm SHA256 .\ThermoLuminescence-1.0.0-win64.zip
Get-Content .\ThermoLuminescence-1.0.0-win64.zip.sha256
```

Хеши должны совпасть (без учёта регистра).

## Обновление на уже установленном компьютере

Начиная со сборки **1.0.0** программа умеет обновляться сама:

1. Откройте вкладку **«Настройки приложения»**.
2. Нажмите **«Проверить обновления»**.
3. Если доступна новая версия — подтвердите скачивание и перезапуск.

Также проверка выполняется тихо при запуске: при наличии новой версии появится диалог.

Обновление заменяет только:

- `main.exe`
- `_internal\`
- `assets\`

Настройки, логи и данные экспериментов **не трогаются**. Во время измерения обновление заблокировано — сначала остановите эксперимент.

Если автоматическое обновление недоступно (очень старая копия без этой функции):

1. Скачайте новый zip с [Releases](https://github.com/Lamblador/ThermoLuminescenceAutomation-releases/releases/latest).
2. Закройте программу.
3. Распакуйте поверх той же папки, **не удаляя** `app_settings.json`, логи и папки с экспериментами (или распакуйте во временную папку и скопируйте только `main.exe`, `_internal` и `assets`).

## Для разработчика: как опубликовать новый релиз

Публикация делается из **репозитория с исходниками** (не из этой папки), скриптом:

```powershell
# 1. Поднять версию в utils/app_version.py, например "1.0.1"
# 2. Из корня исходников:
.\tools\publish_release.ps1
```

Скрипт соберёт приложение, упакует zip, посчитает sha256 и создаст GitHub Release с тегом `v<версия>` в этом репозитории. Существующий тег не перезаписывается.

Нужны: Python venv с зависимостями, локальный `main.spec`, установленный и авторизованный [GitHub CLI](https://cli.github.com/) (`gh auth login`).

## Требования и ограничения

- ОС: Windows x64.
- Первый раз папку со сборкой нужно разложить вручную; дальше — через кнопку обновления.
- Драйверы приборов (DLL спектрометров и т.п.) попадают в сборку только если они были на машине при сборке.
- Репозиторий публичный: скачивание релизов не требует GitHub-аккаунта.
